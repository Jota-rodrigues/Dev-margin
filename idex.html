Box Model

O box model é a forma como o navegador calcula o espaço ocupado por cada elemento na página: conteúdo, padding, border e margin, um dentro do outro, do centro para fora. 

.caixa {
    width: 200px;      /* content   */
    padding: 16px;     /* padding   */
    border: 2px solid; /* border    */
    margin: 24px;      /* margin    */
}

Para que serve na prática?

Margin é a principal ferramenta de espaçamento e composição de layout em CSS.

Separar Elementos

Cria distância entre parágrafos, cards, seções — o "respiro" que evita que tudo pareça colado.

margin-bottom: 1.5rem;

Centralizar Blocos

Com largura definida, um bloco pode ser centralizado horizontalmente sem flexbox nem grid.

margin: 0 auto;

Ajuste fino de posição

Pequenos deslocamentos sem sair do fluxo normal do documento, sem recorrer a position.

margin-top: -4px;

Hierarquia visual

Espaçamentos maiores entre seções e menores entre itens relacionados comunicam estrutura antes mesmo da leitura.

margin: 4rem 0 1rem;

Comportamentos

Colapso de margins

Quando duas margens verticais de elementos irmãos se encontram, elas não se somam — o navegador usa apenas a maior das duas.

caixa 1
caixa 2

Gap real entre as caixas: 0px

Margin-bottom Caixa 1: 0px
Margin-top Caixa 2: 0px

Centraliza blocos

Com uma largura definida, margin-left e margin-right em auto dividem igualmente o espaço restante do contêiner — centralizando o bloco horizontalmente.

caixa 1
Largura da caixa: 160px
CSS aplicado: width: 160px; margin: 0 auto;

Valores negativos

Diferente de padding, a margin aceita valores negativos — puxando o elemento para mais perto (ou sobre) seus vizinhos.

caixa 2
caixa 1
Margin-top Caixa 1: -20px

Porcentagem relativa

Margin em % é sempre calculada a partir da largura do contêiner pai — inclusive para margin-top e margin-bottom. Repare que os dois valores computados abaixo são sempre iguais.

margin: 10%
Largura do container: 400px

margin-top computada: 40px  |  margin-left computada: 40px

Sintaxe rápida

A forma abreviada segue sempre o sentido horário: topo, direita, baixo, esquerda.

  • margin: 10px;/* todos os lados */
  • margin: 10px 20px;/* topo/baixo, direita/esquerda */
  • margin: 10px 20px 15px;/* topo, direita/esquerda, baixo */
  • margin: 10px 20px 15px 5px;/* topo, direita, baixo, esquerda */
  • margin-block: 10px;/* topo + baixo (lógico) */
  • margin-inline: 20px;/* esquerda + direita (lógico) */
